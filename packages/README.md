# packages/

Shared sources that more than one consumer reads — the design tokens, the icons,
the brand assets and the mods that ship built in. A package created before it
has a second consumer is a folder with an import path, so nothing lands here
until something is actually shared.

- `tokens/` — the design tokens. Authored in `src/*.css`, which is the
  authority on every design value in Armada; everything else it holds is
  generated by `cargo xtask verify-tokens`. See its README.
- `icons/` — the icon registry, one TOML file an icon. See its README.
- `brand/` — the app icon and the brand art. See its README.
- `mods/` — mods that ship built in, compiled into Fleet. See its README.
