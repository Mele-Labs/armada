# Does Armada write the person's own Claude folder?

**Decided 2026-10-23.** Asked whether Add to this machine may write skills, sub agents, commands and global instructions into `~/.claude`, he picked "Yes, write it", over keeping the sync to Armada's own pieces. It reverses the line in Kit's two homes that Armada only reads the harness's home.

**Chosen: Add to this machine writes the Claude folder, and plugins install through Claude's own command.** The write is the person's press on one row from the shared home, never Armada's own initiative.

| Asked | He chose | The cost he took |
|---|---|---|
| Does Add to this machine write skills, sub agents, commands and global instructions into his Claude folder | Yes | Armada now writes a folder every other tool he uses reads |
| How a plugin gets there | Claude's own install command, from the name, marketplace and source the home holds | Armada never writes the plugin's files itself, so an install can fail where Claude's does |

**What it keeps.**

- Bring never overwrites a file that differs. Only choosing a side replaces it, and that is a second press.
- Memory notes are written to the Claude folder with the same rule, and a server is never brought: the home holds no key.
- Push to Claude, the automatic part that carries a Kit edit out without a press, is still not built. This decision covers the press and nothing past it.

Where it is written down: `docs/concepts/kit.md`, *Kit's two homes* and *The shared home*.
