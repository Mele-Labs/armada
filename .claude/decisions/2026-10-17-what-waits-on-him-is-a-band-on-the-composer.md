# Where does what waits on him show?

**Decided 2026-10-17.** His words, over four rounds: *"What if questions were like
this. Needs you and questions are little tabs above the composer"*, then *"Even if
there are multiple things that need me, I should see a list of them when this
opens ... It should never bombard me with all at once"*, then *"When I click the
band, it slides up with the panel in a smooth animation. It becomes the panel
header. The session thread behind it should dim."*, then *"Let's make the same
thing happen for the 'Session end' and 'judges' panel."*

**Chosen: one band on the composer that opens as a list.** Approved on
`?walk=needs-you-panel` and `?walk=session-end-band`, over a tab-shaped take that
was walked beside it and dropped.

| Asked | He chose | The cost he took |
|---|---|---|
| Where a question sits | A row in the Needs you panel, first, not a card at the thread's tail | The thread no longer holds the ask |
| What opens | A list, a row each and no act on the row; a row opens its one thing | One more press to answer |
| What a question does on arrival | Opens the panel once, to the list, and not again after folding | None |
| How it opens | The band rides up as the panel's header, the thread dims, a press on the thread folds it | A scrim over the thread while it is open |
| Judges | Rows in the same list, after the question | None |
| Session end | Its own band in the done hue, folded, opened only by a press; Needs you wins the slot | The made list is one press away |

**What it keeps.** A plan to approve is still the thread's last card, with the
chip that jumps back to it. Esc keeps its Cockpit meaning: the panel marks
itself so the Cockpit's own Esc passes it by while it is open.
