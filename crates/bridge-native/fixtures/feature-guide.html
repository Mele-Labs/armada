Feature pages

Every feature Armada knows has a page of its own. The page says what the feature does for you, which tests prove it and where its code lives. Jobs write and keep these pages, and Fleet reads them to tell when one no longer matches the code.

This guide is what a Job reads before it writes one. It settles how a page is laid out, what it must name, and when it counts as stale, so the Features screen can list every page the same way.

What a page holds

A title in the words you would use for the feature, one paragraph on what it does for you, the tests that prove it, and the paths its code lives under. A page may carry drawings of its screens. It carries no history: the pull requests that changed the feature are listed by Fleet beside it.

Decisions

DecisionWhy
One page for each featureA feature split over two pages drifts: each half is edited without the other.
A page names its tests by pathFleet checks each path on main, so a test that moves marks the page stale.
Stale is a rule you setThirty days untouched suits a quiet feature and not a busy one.
The Job that changes a feature rewrites its pageIt knows what moved, and its plan already names the page.
A page draws its screens rather than pictures themA drawing names its parts; a picture of a screen is out of date the day the screen changes.
Pages live beside the codeA pull request that moves the code moves the page in the same review.

How a page goes stale

When a change lands, Fleet reads every page whose paths it touched and checks them against the stale rule. A page that fails is marked on its row, and the Job that owns the feature is asked to rewrite it.

Where pages live

Pages sit under each feature's own folder, beside the code they describe, so a move of the code is a move of the page in the same pull request. The Features screen reads them from main and shows the newest.

What is left open

Whether a page should list the tests it owns by name as well as by path is still asked of you on this Job. Until it is answered, pages name paths only.
