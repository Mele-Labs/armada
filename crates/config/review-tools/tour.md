---
kind: tool
name: Tour
---
Lay out a tour of this change for a person reading it for the first time. Find where the change is entered, the route, command, handler or exported function a caller reaches first, and start there. Then follow the change the way it runs, one stop for each piece a reader has to see, and say in one line what that piece does. Read the checkout to find the real order, not the order the files are listed in. Leave out lockfiles, generated files and pure renames, and pin each stop to the hunk it is about.
