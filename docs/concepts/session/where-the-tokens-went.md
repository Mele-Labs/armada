# Where the tokens went

**Part of:** [Job](../session.md).

**Fleet keeps the usage of every turn, as well as the latest figures.** `usage` on the record stays the last `context_tokens`, `context_window` and `cost_micros`. Beside it, `session_turn_usage` holds a row for each answered message: its id, when, the model, input, cache-creation, cache-read and output tokens, the names of the tools the turn called, whether a subagent answered it, and, where its first call was a shell command, a `bash_use` label: `read_search`, `scripts`, `git`, `build_test`, `loops_waits`, `forge` or `other`, from the first real command once any leading `cd x &&` is gone. A message heard twice is one row: the larger output wins the figures and the calls are joined, because a harness writes the same message as it streams, a line for each block. `get_session_usage` returns a job's turns for a window of time, oldest first; adding the rows by model, tool or label is the reader's. Names and counts only: no tool input or message text, and a label is not the command.

**Nothing has to report a turn.** Fleet reads the agent CLI's transcripts itself, `<project>/<session>.jsonl` and the subagents' under `<project>/<session>/subagents/`, in `crates/fleet/src/turn_ingest.rs`. The files of every live job are read on the notice loop from the offset the last read reached, and a while after start the files written to in the last seven days are read once, one at a time with a pause between, so a week of jobs does not load the machine. The offset of each file is kept in `transcript_offsets` with the turns it gave, so a restart reads only what was appended. A job found under several project folders is counted once, by its largest file. A transcript of a job Fleet does not know gets rows too. `docs/practices/protocol.md`, *Usage a turn at a time*, has the wire.

**The Usage page reads sums, not rows.** `get_usage_summary` adds the kept turns over a window in SQL and returns burn in cost units (input 1, cache-creation 1.25, cache-read 0.1, output 5, over a million): the total split by model, token kind, first tool, shell use, day and weekday-by-hour in the caller's local time, the thirty largest Jobs the same way with the rest rolled into one, and the equal period before for comparison. `docs/practices/protocol.md`, *The usage summary*.
